# Employee Management System

Eine Fullstack-Webanwendung zur Verwaltung von Mitarbeitenden.  
Das Projekt besteht aus einem Spring-Boot-Backend mit REST API und einem React-Frontend.

## Funktionen

- Mitarbeitende anzeigen
- Neue Mitarbeitende hinzufügen
- Daten von Mitarbeitenden bearbeiten
- Mitarbeitende löschen
- Validierung der Eingabedaten

## Technologien

### Backend
- Java
- Spring Boot
- Spring Data JPA / Hibernate
- MySQL
- Maven
- ModelMapper

### Frontend
- React
- JavaScript
- HTML
- Axios
- Bootstrap
- React Router
- Vite




## Datenbank

Die Anwendung verwendet MySQL zur Speicherung der Daten von Mitarbeitenden.

## Über das Projekt

Das Projekt wurde erstellt, um die Entwicklung einer vollständigen Webanwendung mit Spring Boot und React praktisch umzusetzen. Dabei werden Frontend und Backend über eine REST API miteinander verbunden.
